# 影片心率和Adobe訪客ID服務 {#video-heartbeat-and-the-experience-cloud-id-service}

視訊心率需要訪客ID服務。 在測量JavaScript或Flash上的視訊時，在您的網站頁面上與視訊播放中實作訪客ID服務，可確保在訪客檢視視訊時不會個別計算訪客。
